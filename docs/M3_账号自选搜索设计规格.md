# M3 — 账号 + 自选股 + 搜索 设计规格

> 用途:给 Claude Code 的实现蓝图,涵盖前后端。这是 MVP 的最后一块功能。
> 落地依据:前面线框——自选在左侧栏、搜索在顶栏、红涨绿跌。

---

## 1. M3 目标与范围

加上多用户账号(邮箱+密码)、自选股管理、标的搜索,并把 M2 的"最简选标的"换成从自选/搜索选,数据按用户隔离。

**M3 做**:注册/登录、自选 CRUD、搜索、把对比/看图的标的来源接到自选+搜索。
**M3 不做**:盘后自动更新 + 上云部署(M4)。

**M3 完成 = MVP 主体功能齐全。**

---

## 2. 前置数据准备:全市场标的列表

搜索需要 `instruments` 表有**全量 A 股代码 + 名称**。M0 是按需加载**行情**,但标的列表要**全量预加载**。

所以 M3 第一步:写个初始化脚本,用 Baostock/AKShare 拉全市场标的列表(代码、名称、市场、类型 stock/index,含沪深300 等指数)灌进 `instruments`。这是搜索的数据基础。

---

## 3. 一个最容易搞错的原则:什么按用户隔离,什么全局共享

- **按用户隔离**:`users`、`watchlist`(自选)、对比组合 —— 每人一份。
- **全局共享**:`daily_bars`(行情)、`instruments`(标的列表)—— 所有用户共用一份。任一用户按需抓进库的票,所有人都能直接用。

**别把行情也按 user 隔离了**——那会导致重复抓取、浪费,也违背 M0 的设计。加了账号只隔离"自选和对比组合",行情照旧共享。

---

## 4. 后端

### 4.1 用户体系
- `users` 表(M0 已预留):`id, email(unique), password_hash, created_at`。
- `POST /api/auth/register`:邮箱+密码 → 密码用 **passlib + bcrypt 哈希**存储 → 建用户。
- `POST /api/auth/login`:校验 → 签发 **JWT**。
- 认证依赖:FastAPI dependency 校验 JWT、取出 `user_id`,保护需登录的接口。
- 安全:密码**绝不明文**;邮箱唯一约束;JWT 设有效期。

### 4.2 自选股
- `watchlist` 表(M0 已预留):`user_id, symbol, added_at`,PK `(user_id, symbol)`。
- `GET /api/watchlist`:当前用户的自选(带最新价 + 当日涨跌幅)。
- `POST /api/watchlist {symbol}`:加自选 → **顺便异步触发**该股行情按需抓取入库(这样列表能显示涨跌幅)。
- `DELETE /api/watchlist/{symbol}`:删自选。
- 全部从 JWT 取 `user_id` 隔离。

### 4.3 搜索
- `GET /api/search?q=`:查 `instruments`,**代码精确 + 名称模糊**,返回代码+名称。
- 拼音首字母联想是加分项,非必须。

---

## 5. 前端

### 5.1 登录 / 注册
- 登录页、注册页(邮箱+密码)。
- token 管理:登录后存 token,请求带 `Authorization` 头,过期则跳登录。
- 路由守卫:未登录跳登录页。

### 5.2 自选股管理(左侧栏)
- 列表项:代码 / 名称 / 最新价 / 涨跌幅(**红涨绿跌**)。
- 加 / 删自选。
- 从自选项 → 看图(单股),或勾选进对比(M2)。

### 5.3 搜索(顶栏)
- 输入联想。
- 选中结果 → 加自选 或 直接看图。
- 搜到未入库的票,看图/加自选时触发按需抓取。

### 5.4 串起来
- 把 M2 的"最简选标的"替换成:**从自选勾选 / 从搜索选**。
- 登录后才有自己的自选和对比组合。

---

## 6. 关键决策点

- **JWT 存哪**:`localStorage`(简单,但要防 XSS)vs `httpOnly cookie`(防 XSS 更稳)。MVP 用 localStorage 也行,想稳用 httpOnly cookie。
- **加自选触发抓取要异步**,别阻塞请求/卡 UI。

---

## 7. M3 验收标准

1. 注册 + 登录正常;数据库里 `password_hash` 是哈希、**看不到明文**。
2. 登录后看到自己的自选;换个账号是另一份(隔离生效)。
3. 搜索"茅台"能联想到 `600519.SH`,选中能看图 / 加自选。
4. 加自选后列表显示最新价 + 涨跌幅,删除正常。
5. 从自选选多只进对比(M2)正常。
6. 未登录访问受保护接口被拦 / 跳登录。
7. 两个账号各自的自选互不可见,但看同一只票的 K 线数据是同一份(行情共享)。

跑通这 7 条,M3 完成,**MVP 主体功能就齐了**。

---

## 8. 给 Claude Code 注意点

- 密码用 passlib + bcrypt 哈希,**绝不明文**。
- JWT 取 `user_id` 做隔离:自选、对比组合按用户隔离;**行情和标的列表全局共享,别隔离**(见第 3 节)。
- 搜索前先把 `instruments` 全量标的导入(第 2 节)。
- 加自选触发抓取走异步。

---

## 9. 下一步:M4 — MVP 收尾

- **盘后自动更新**:定时任务,仅交易日执行,增量更新已入库标的(用 M0 的交易日历 + coverage)。

- 做完 M4,MVP 完整上线,你和朋友就能用了。
