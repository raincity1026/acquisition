# M2 — 多股归一化对比 设计规格

> 用途:给 Claude Code 的实现蓝图,涵盖前后端。这是本工具的差异化核心。
> 落地依据:前面那张对比态线框(主图叠加 + 归一化 + 基准日竖线 + 百分比轴 + 图例带涨跌幅 + 隐藏指标)。

---

## 1. M2 目标与范围

让用户把多只股票(含指数)叠加到一张图,以某个基准日为起点,按**累计涨跌幅**对比谁更强。

**M2 做**:`/api/compare` 后端(对齐 + 归一化)、前端对比态(归一化折线、基准日可调、图例、对数轴、加/减标的)。
**M2 不做**:完整的自选/搜索(M3)。M2 先用**最简方式**选标的(如输入框输入多个代码,或一个临时的添加列表),等 M3 再接自选股。

---

## 2. 关键技术决策:对比折线用什么画

**klinecharts 是为单标的蜡烛图设计的,不擅长叠加多标的折线对比。** 所以对比态的归一化折线图,建议**换一个通用图表库**画,而不是硬塞进 klinecharts:

- 推荐 **ECharts**(中文生态成熟、多 series 折线 / 对数轴 / tooltip / 图例全部开箱即用),或 **Lightweight Charts 的 line series**(更轻、专为金融)。
- 我略偏 **ECharts**,因为对数轴、多线 tooltip、图例这些 M2 要的功能它现成最全。
- 让 Claude Code 先评估:klinecharts 当前版本若能优雅叠加多标的折线也可以,但别为此把它用得很 hack。

所以前端会变成:**单股态(K 线)用 klinecharts,对比态(归一化折线)用 ECharts**。两种图性质不同,各用擅长的库,这是合理的。

## 3. 后端:`/api/compare`

### 3.1 API 契约
```
GET /api/compare?symbols=600519.SH,000858.SH,000300.SH&base_date=2024-01-02&start=&end=
```
返回:
```json
{
  "base_date": "2024-01-02",
  "dates": ["2024-01-02", "2024-01-03", ...],
  "series": [
    { "symbol": "600519.SH", "name": "贵州茅台", "values": [0, 1.2, ...], "latest_pct": 38.2 },
    { "symbol": "000300.SH",  "name": "沪深300",  "values": [0, -0.3, ...], "latest_pct": -4.8 }
  ]
}
```
- `dates`:统一交易日轴(所有标的对齐到它)。
- `values`:每个标的的**累计涨跌幅(%)**,与 `dates` 等长对齐,基准日当天 = 0。
- `latest_pct`:最新一天的累计涨跌幅,给图例显示用。

### 3.2 归一化算法(核心,要算对)
- 每个标的取**后复权 close** 序列(涨跌幅与复权方式无关,用后复权最稳)。
- 基准价 `P0` = 该标的在 `base_date` 的后复权 close。
- 每天:`value_t = (close_t / P0 − 1) × 100`。
- 基准日当天 = 0;基准日之前留空(`null`)。

### 3.3 对齐规则(`align`,M0 §5.5 已定契约)
- 统一交易日轴 = A 股交易日历在 `[start, end]` 的交易日(M0 已有日历)。
- 每个标的对齐到该轴:
  - 正常交易日:用当天数据。
  - 停牌日(`trade_status=0`)或缺口(超长停牌):用**前值横线填充**。
  - 上市前:留空(`null`),不参与。
- **base_date 默认取所有选中标的都已有数据的最早共同交易日**,规避"某标的在基准日尚未上市"的麻烦;用户可往后调。

## 4. 前端:对比态 UI

### 4.1 单股 → 对比态切换
延续线框方案:单股态(klinecharts 蜡烛)下,用户**添加第二个标的** → 切到对比态(ECharts 归一化折线);减回一只 → 退回单股态。

### 4.2 归一化折线图(ECharts)
- 多条 line series,从基准日的 0% 发散。
- Y 轴:百分比(`+40% / +20% / 0% / −20%`),0% 是基准线。
- 基准日:一条竖虚线标在图上。
- X 轴:统一交易日轴。
- 线色:用于**区分标的**(蓝/珊瑚/青…),与图例同色。

### 4.3 控件
- **基准日**:可选/可调,默认对比区间起点。改基准日 → 重新请求 `/api/compare`。
- **图例**:每个标的 颜色点 + 名称 + 当前累计涨跌幅(`latest_pct`),涨跌幅按 A 股红涨绿跌。
- **对数轴**:可选开关(看长期涨幅更合理)。
- **加/减标的**:M2 用最简输入或临时列表;上限建议 **≤8 只**(再多视觉乱、性能降)。
- **隐藏指标**:对比态**不显示**成交量/MACD 等(多标的指标无法同图比较)。指标只在单股态出现。

---

## 5. 交互

- 加标的 → 若当前是单股,切对比态并重新走 `/api/compare`。
- 减标的 → 减到一只时退回单股 K 线态。
- 调基准日 → 重新请求,曲线重新以新基准发散。
- 切对数轴 → 前端切 ECharts 的 Y 轴类型(无需重新请求)。
- 十字光标 / tooltip:显示各标的当天的累计涨跌幅(ECharts 自带)。

---

## 6. M2 验收标准

1. 选 2-3 只标的(如茅台 + 五粮液 + 沪深300),显示归一化折线,各自从基准日 0% 发散。
2. 基准日当天所有线都 = 0%;`latest_pct` 与图例显示一致。
3. 量纲差异大的标的(高价 vs 低价)也能同图清晰对比(归一化生效)。
4. 改基准日,曲线重新发散、数值随之变。
5. 停牌日不破图(横线连续),上市晚的标的从其起点起。
6. 对数轴切换正常。
7. 加到第 1 只时回到单股 K 线态。

跑通这 7 条,M2 完成——工具的核心价值就成立了。

---

## 7. 给 Claude Code 注意点

- 归一化**用后复权 close 算累计涨跌幅**,别用前复权或不复权(结果虽接近但后复权最稳;关键是别忘了是"涨跌幅"不是"价格")。
- 基准日不是交易日时,取之后第一个交易日。
- 对齐务必走统一交易日轴 + 停牌前值填充,否则多线会错位。
- 对比折线建议用 ECharts(或 Lightweight Charts),别硬塞 klinecharts。
- 对比态隐藏指标——这是定好的产品决策。
- 标的上限 ≤8。
