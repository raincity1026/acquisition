每只票对应一类要踩的坑，别只测一只白马股就以为没问题：

| 标的 | 代码 | 验证目的 |

## 2. 验证清单（逐项核对）

### ✅ 2.1 基础连通与字段完整性
- 能拉到日线，且包含：日期、开、高、低、收、成交量、成交额、涨跌幅。
- **通过标准**：返回非空，字段齐全，日期连续（按交易日）。

### ✅ 2.2 复权正确性（最关键）
- 对茅台分别拉**不复权 / 前复权 / 后复权**三个版本，定位最近一次除权除息日。
- **通过标准**：
  - 不复权：除权日相对前一日有明显跳空（"假摔"）。
  - 后复权：除权日前后曲线连续、无假跳空；且**重复拉取历史值不变**。
  - 前复权：最新一天的价格 = 当前真实价；除权日附近同样连续。
  - 三者在最近一段（最后一次除权之后）应当数值一致。

### ✅ 2.3 停牌处理
- 拉那只停牌过的票，观察停牌期间是**跳过该日期**、还是**返回空值占位**。
- **通过标准**：能稳定判断"哪些交易日缺数据"——这决定后面多股对齐的填充逻辑。

### ✅ 2.4 周/月聚合
- 用日线聚合出周线、月线（或对比数据源直接给的周月线）。
- **通过标准**：聚合出的周/月 OHLC 合理（周开=周一开、周高=周内最高……）。

### ✅ 2.5 数据源一致性（主备对比）
- 同一只票，Baostock 和 AKShare 各拉一份后复权，对齐日期比较收盘价。
- **通过标准**：基本一致；若有系统性偏差，记录下来——**同一标的今后固定用一个源**，避免拼接对不齐。

### ✅ 2.6 标的列表（支撑搜索）
- 获取全市场 A 股代码 + 名称列表。
- **通过标准**：能拿到完整列表（数千条），字段含代码和名称。

### ✅ 2.7 指数拉取
- 拉沪深300（000300）日线。
- **通过标准**：返回正常，可与个股同图对比。

### ✅ 2.8 交易日历
- 获取 A 股交易日历（用于对齐与盘后定时任务触发）。
- **通过标准**：能拿到交易日序列，正确排除周末与节假日。

### ✅ 2.9 性能/体验
- 记录"拉一只票近 2 年日线"的耗时。
- **通过标准**：耗时可接受（按需加载场景，单只应在数秒内）。

## 3. 参考脚本骨架

> 仅作起点。AKShare 接口名偶有变动，**让 Claude Code 对照 baostock / akshare 最新文档核对接口名与参数**后再跑。复权标志务必显式指定，别用默认。

```python
import baostock as bs
import akshare as ak
import pandas as pd

# ---------- Baostock：复权三连对比 ----------
def baostock_kline(code="sh.600519", start="2023-01-01", end="2024-12-31", adjustflag="1"):
    # adjustflag: 1=后复权, 2=前复权, 3=不复权
    fields = "date,open,high,low,close,volume,amount,pctChg"
    rs = bs.query_history_k_data_plus(code, fields,
                                      start_date=start, end_date=end,
                                      frequency="d", adjustflag=adjustflag)
    return rs.get_data()

bs.login()
df_raw  = baostock_kline(adjustflag="3")   # 不复权
df_qfq  = baostock_kline(adjustflag="2")   # 前复权
df_hfq  = baostock_kline(adjustflag="1")   # 后复权
bs.logout()
# 对比三者在最近一次除权日附近的 close，确认 2.2 的通过标准

# ---------- AKShare：主备一致性 + 列表 + 指数 + 日历 ----------
ak_hfq = ak.stock_zh_a_hist(symbol="600519", period="daily",
                            start_date="20230101", end_date="20241231",
                            adjust="hfq")          # qfq/hfq/""(不复权)

code_name = ak.stock_info_a_code_name()            # 全市场代码+名称（2.6）
hs300     = ak.index_zh_a_hist(symbol="000300", period="daily",
                               start_date="20230101", end_date="20241231")  # 指数（2.7）
trade_cal = ak.tool_trade_date_hist_sina()         # 交易日历（2.8）

# 对齐日期，比较 Baostock 与 AKShare 的后复权收盘价（2.5）
```
