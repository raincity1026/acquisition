## 2. 盘后自动更新【代码:Claude Code 做】

### 2.1 任务逻辑
- **定时触发**:每个交易日盘后。建议 **18:00–19:00 之后**——A 股 15:00 收盘,但数据源通常傍晚才把当天数据更新完整,太早跑会拿不到当天。
- **仅交易日执行**:用 M0 的交易日历判断,非交易日直接跳过。
- **更新范围**:遍历所有**已入库标的**(`instruments` 里 coverage 非空的)。注意是全部已入库的,不是某个用户的自选——因为行情全局共享。
- **增量**:从每只的 `coverage.data_end` 拉到最新 → `upsert_bars` → 更新 coverage。后复权历史不变、只追加。
- **稳健做法**:增量时**重叠拉最近几天**(从 data_end 往前 3–5 天开始),覆盖更新,防数据源对近期数据做过修正。

### 2.2 容错(呼应 spike 结论)
- baostock 失败 → 重试 → 降级 AKShare(走 sina)。
- **单只失败不影响其他**:记录失败、继续跑,失败的票下次再试。

### 2.3 调度实现
- **APScheduler**(后端进程内调度)或系统 **cron** 触发脚本。
- 必须跑在**常驻服务器**上——serverless 跑不了(前面 Vercel 那轮讲过)。

---

## 3. 上云部署【运维:你做 + 配置代码:Claude Code 做】

### 3.1 架构(前面定的)
一台轻量云服务器 + Docker Compose,一台机器全搞定:
- FastAPI(后端 + APScheduler 定时任务)
- PostgreSQL
- Nginx(反代 + 托管前端静态文件)

【Claude Code 做】`Dockerfile`、`docker-compose.yml`、Nginx 配置、环境变量管理。
【你做】买服务器、跑部署。

### 3.2 节点选择【你做】
- **香港节点**:免备案、数据源和访问还行 → MVP 省事之选。
- **大陆节点**:数据源最优、访问最快,但要 **ICP 备案 + 公安备案**。
- 海外 / Vercel:**不行**(抓 A 股数据源地域问题)。

### 3.3 数据库【配置:Claude Code / 运维:你】
- PostgreSQL 用 compose 起容器,**数据持久化到磁盘卷(volume)**——别让容器重启丢数据。
- **备份**:定期 `pg_dump`(MVP 至少配个定时备份)。

### 3.4 前端部署【Claude Code 配 / 你跑】
- Vue `build` → 静态文件 → Nginx 托管。
- `/api` 反代给 FastAPI(**同域,免跨域**)。
- 或前端放国内 CDN / 对象存储(**别用 Vercel**,国内访问不稳)。

### 3.5 域名 + 备案 + HTTPS【你做为主】
- 买域名、配 DNS 指向服务器。
- 大陆节点:域名先 **ICP 备案**(十几到二十几天,提前做)+ 上线后公安备案。
- 香港节点:无需备案,直接配。
- **HTTPS**:Let's Encrypt 免费证书(certbot)或云厂商证书。【certbot 脚本 Claude Code 可帮配】

### 3.6 部署后必做:重新验证数据源连通【你做】
云节点网络和你本地不同,**部署后先在那台机器上验证 baostock 登录 + akshare 抓取通不通**——这是之前 spike 的云端版。本地通不代表云上通,尤其要确认选的节点抓国内数据源没问题。

## 4. 环境与配置【Claude Code 做】
- 数据库连接、JWT 密钥、数据源配置等用**环境变量 / .env**,别硬编码。
- **JWT 密钥、数据库密码等敏感信息别进代码库**(.gitignore)。
- 生产关掉 debug、配好日志。

---

## 5. M4 验收标准

1. 定时任务在交易日盘后自动跑,已入库标的更新到最新。
2. 非交易日不跑(交易日历生效)。
3. 某只票抓取失败不影响其他,有重试 / 降级。
4. 公网域名能访问前端,前端能正常调后端 API。
5. HTTPS 正常(绿锁)。
6. 容器重启数据不丢(数据卷持久化)。
7. 云节点能正常抓数据源(连通性验证通过)。

跑通这 7 条,**MVP 完整上线**。

---

## 6. 给 Claude Code 注意点
- 定时任务常驻(APScheduler / cron),不是 serverless。
- 增量更新重叠拉最近几天,防近期数据修正。
- 容错:单只失败隔离、重试、降级。
- 敏感配置走环境变量,别进代码库。
- 数据卷持久化。
