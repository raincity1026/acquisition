## 关键证据：复权三连在除权日前后的 close（肉眼确认连续、无假跳空）

茅台近 3.5 年共 6 个除权除息日（现每年两次分红）。检测法：不复权日收益率 `raw_ret` 与后复权（真实）日收益率 `hfq_ret` 背离即除权日。

以最近一次 **2025-12-19** 为例：

```
mark       date  raw_close   qfq_close    hfq_close   raw_ret   hfq_ret
     2025-12-16    1422.00 1398.190032 10475.198550 -0.280505 -0.280505
     2025-12-17    1433.10 1409.104174 10556.966978  0.780591  0.780591
     2025-12-18    1431.00 1407.039336 10541.497275 -0.146535 -0.146535
   ★ 2025-12-19    1410.00 1410.000000 10563.674880 -1.467505  0.210384   ← 除权当日
     2025-12-22    1408.26 1408.260000 10550.638856 -0.123404 -0.123404
     2025-12-23    1407.86 1407.860000 10547.642068 -0.028404 -0.028404
```

- **不复权**：除权日 `raw_ret = -1.47%`（账面跳空下跌），但真实当日 `hfq_ret = +0.21%` → 这就是"假摔"。
- **后复权**：除权日 `hfq_ret = +0.21%` = 真实涨跌，曲线连续、无假跳空。
- **前复权**：同样连续；且除权日之后 `qfq_close == raw_close`（1410.00==1410.00…）。
- **除权日前后一天** `raw_ret == hfq_ret`（完全相等）→ 假摔只出现在除权当日，别处无伪跳空。

补充硬指标：
- 最新交易日 2026-06-15：前复权 close (1271.1) == 不复权 close (1271.1)，差 **0.0000** → 前复权最新=真实价 ✓
- 后复权重复拉取 833 行历史 close，最大差 **0.00000000** → 历史值不漂移，可安全入库 ✓
- 后复权为整体等比例缩放（hfq ≈ raw × IPO 以来累计复权因子），故 hfq 绝对值远大于 raw，但**连续性与收益率口径完全正确**——文档"三者数值一致"应理解为"前复权与不复权在最后一次除权后一致；后复权为等比缩放，连续性同样成立"。

## 踩到的坑（给后续搭框架的提醒）

1. **baostock 调用 pandas 已移除的 `DataFrame.append`**（pandas≥2.0）。需 `spike/_compat.py` 垫片，在 `import baostock` 前先 `import _compat`。否则首次 `get_data()` 即报错。
2. **AKShare eastmoney 端点（`stock_zh_a_hist` / `index_zh_a_hist` / `stock_zh_a_spot_em`）在本环境频繁 `Connection reset / RemoteDisconnected`**，疑似 IP 限流。改用 **sina 系端点**（`stock_zh_a_daily` / `stock_zh_index_daily` / `tool_trade_date_hist_sina`）后稳定且更快。备用源代码里要带退避重试 + 端点回退。
3. 代码格式：Baostock `sh.600519`/`sz.000040`，AKShare 纯 `600519` 或 `sh600519`（按接口）。
4. 复权标志务必显式：Baostock `adjustflag` 1=后复权/2=前复权/3=不复权（默认不复权）；AKShare `adjust=""`/`qfq`/`hfq`。
